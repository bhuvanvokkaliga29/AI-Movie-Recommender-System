---

## 🧠 What This Project Does

This is a **content-based movie recommendation system** that suggests movies similar to the one you select.

It uses:
- 🧠 NLP (Bag of Words)
- 📊 Cosine Similarity
- 🎬 Movie metadata (genre, overview, keywords)

to generate **highly relevant recommendations instantly**.

---

## ⚙️ How It Works

1. 📥 Load movie dataset  
2. 🧹 Clean and combine metadata  
3. 🧠 Convert text → vectors using NLP  
4. 📊 Compute similarity using cosine similarity  
5. 🎬 Show top 5 recommended movies
